FAQ

1) The app doesn’t load words

The app uses an online server for word data. If the server is sleeping or there is no internet connection, the game may not load. Please try again in 20–40 seconds.

2) I found a wrong hint / spelling mistake

Thank you! Please send us a message with the word, hint and screenshot. We will fix it in the next update.
